### LLM policy & disclosure

My goal is to keep my own LLM usage for this project to
[level 2](https://www.visidata.org/blog/2026/ai/) or less.

I don't expect a lot of contributions to this software (if any), but if you do
want to contribute, I'd ask for:

* entirely human-written PR descriptions and commits
* almost entirely human-written code (as described in [level 2](https://www.visidata.org/blog/2026/ai/) here)

If you'd like to make a contribution but don't have the time to write the code
yourself, please make an issue instead.
