# a docs feedback site

This is a project for getting feedback from users on documentation.

You can see what it looks like to use as a user here: https://docs-feedback.wizardzines.com/doc/test-page

It's heavily inspired by [help this book](https://helpthisbook.com/), but with some UI differences (users can't see each others' comments, slightly different feedback prompts, no support for writing "books").

### how it works

It's a Vue single page app that uses [Pocketbase](https://pocketbase.io/) as the backend.

### LLM policy & disclosure

My goal is to keep my own LLM usage for this project to
[level 2](https://www.visidata.org/blog/2026/ai/) or less. It's important to me to understand the code.

I don't expect a lot of contributions to this software (if any), but if you do
want to contribute, I'd ask for:

* you to write all commits and PR descriptions yourself
* you to write almost all the code yourself (as described in [level 2](https://www.visidata.org/blog/2026/ai/) here)

If you'd like to make a contribution but don't have the time to write the code
yourself, please make an issue instead.
